FastAPI + SQLAlchemy + Alembic + Pydantic + Uvicorn

- FastAPI: API framework (handles data requests quickly)
- SQLAlchemy: database operations (makes storing and finding things in database simpler)
- Alembic: database changes (changing organization of database safer)
- Pydantic: data validation (ensures data going in/out is correct and complete)
- Uvicorn: serving the application (keeps the app running)
